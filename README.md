# 📊 Advanced Credit Risk Analytics and Loan Default Prediction

## Overview

This project develops an end-to-end credit risk assessment system to identify high-risk borrowers and predict loan defaults using Machine Learning, Predictive Analytics, Explainable AI, and Power BI dashboards.
The objective is to support data-driven lending decisions, improve portfolio quality, and minimize credit losses.

## 🎯 Objective

To develop an advanced credit risk analytics framework for identifying high-risk borrowers and predicting loan defaults using machine learning, customer segmentation, and interactive Power BI dashboards.

## 📌 Key Insights

- Portfolio default rate is 21.9%, significantly above the target threshold of 5%.
- Grade G borrowers exhibit the highest default risk.
- Low-income customers and renters show greater default tendencies.
- Debt-to-Income Ratio is the strongest predictor of loan default.
- XGBoost outperformed all other machine learning models.
- High-risk customers constitute the largest risk segment of the portfolio.
